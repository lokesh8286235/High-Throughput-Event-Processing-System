# Contributing

This repository focuses on reliable asynchronous event processing and operational resilience.

## Development standards

- Preserve retry, idempotency, and dead-letter behavior when modifying event flows.
- Add tests for failure and recovery paths.
- Document changes affecting infrastructure or message semantics.
- Keep observability signals aligned with production behavior.

## Pull Requests

Explain the failure mode or capability being addressed, the implementation, how it was tested, and any effect on throughput, latency, reliability, or cost.
